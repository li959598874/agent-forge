# Support

Use GitHub issues for public support:

- Bug reports: use the bug report template.
- Feature requests: use the feature request template.
- Usage questions: include your Codex version, plugin install method, command used, and relevant repository context.

For security concerns, follow [SECURITY.md](SECURITY.md) instead of opening a public issue.

This project is maintained on a best-effort basis. Clear reproduction steps and focused examples make support faster.
