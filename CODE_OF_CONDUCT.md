# Code of Conduct

Agent Forge uses a simple contributor standard: be direct, professional, and respectful.

## Expected Behavior

- Discuss ideas and tradeoffs on technical merit.
- Keep feedback actionable and specific.
- Respect maintainers' scope decisions.
- Assume good intent while still naming concrete risks.

## Unacceptable Behavior

- Harassment, threats, or personal attacks.
- Discriminatory language or behavior.
- Publishing private information without permission.
- Repeated off-topic disruption after maintainers ask for focus.

## Enforcement

Maintainers may edit, hide, or close issues and pull requests that violate this standard. Serious or repeated violations may lead to blocked participation in the project.

Report conduct concerns to the maintainer through GitHub profile contact options or a private GitHub channel when available. Do not publish sensitive personal details in public issues.
